# Contributing a reading

Found a paper that belongs on this list? Open a PR.

1. Edit the relevant `tier{1,2,3}/<section>.md` file, under its `## Reading` heading.
2. Add one bullet per reading, in this format:

   ```
   - **Author (Year)** — *Title.* Venue. One-line note on why it matters.
   ```

3. Mark genuinely foundational readings with a leading ⭐ (sparingly — it means
   "if you read nothing else in this section, read this").
4. Open a PR. A maintainer reconciles it back into the private source of truth
   (the YAML masters this list is generated from) — don't worry about matching
   that format exactly, just get the reading and the reasoning down.

Thanks for helping keep this list sharp.
